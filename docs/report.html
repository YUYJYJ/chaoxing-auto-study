踩过的坑 & 修法

现象根因修法
填空题永远交空值 超星字段是 answerEditor{题号}{空号}，且 HTML 里只有第 1 空，其余由 JS 动态生成 按 tiankongsize{题号} 补齐全部空位，答案用逗号拆分到各空
提交报「作业提交失败！」 单选要的是选项字母，不是选项原文 统一转换层：单选→字母 / 多选→字母串 / 判断→true·false
刷一遍就卡住不动 章节是链式解锁的：做完第 N 章才开 N+1 改成「做测验 → 刷视频 → 读进度」循环，直到无增量
题目全是乱码 超星用 @font-face 把题面换成自定义字形 用字体映射表反解还原真实文字
答案表对不上题 平台题干用不换行空格 \xa0 和中文弯引号 标题归一化 + 模糊匹配（cutoff 0.75）
分数忽高忽低 上游错题解析依赖「正确答案」文本，而该页根本不返回 改读页面的 marking_cuo 标记定位错题
长时间跑易 403 超星按 IP 限频 代理池 + 失败自动轮换（可选）
